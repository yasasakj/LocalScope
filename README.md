# LocalScope - "Что вокруг меня"

Мобильное и веб-приложение для получения сводки информации вокруг пользователя: погода, прогноз и подборки мест рядом (кафе, рестораны, аптеки, достопримечательности).

## 🎯 Основные возможности

- 🌤️ **Погода**: текущая погода и прогноз на несколько дней (через Open-Meteo API)
- 📍 **Геокодирование**: преобразование адреса в координаты (Яндекс Геокодер)
- 🍴 **Места рядом**: поиск кафе, ресторанов, аптек и других мест (Яндекс Search API)
- 🎯 **Скоринг мест**: автоматическая оценка по расстоянию, рейтингу и статусу открытия
- 💨 **Оценка комфорта**: анализ комфортности погоды на основе температуры, ветра и осадков
